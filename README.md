# Sketch Pals

Dessine tes amis préférés dans ce jeu de création artistique !

## Comment jouer

 Prends le stylo, le pinceau ou la gomme et laisse libre cours à ton imagination. Dessine vos amis, vos champions ou ce que tu veux, puis sauvegarde ton œuvre en un clic !

**En bref :** Choisis ton outil → Dessine sur le canvas → Sauvegère ton tableau en PNG

## Contrôles

### Ordinateur (clavier + souris)
- **Souris** : Cliquer et glisser pour dessiner sur le canvas
- **Boutons toolbar** : Changer d'outil (Stylo / Pinceau / Gomme / Effacer)
- **Bouton Sauver** : Télécharge ton dessin en PNG
- **Clic + glisser** : Dessiner avec l'outil sélectionné

### Mobile / Tablette (écran tactile)
- **Touch** : Toucher et glisser pour dessiner directement
- **Boutons toolbar** : Changer d'outil (même fonctionnement)
- **Fabric.js** gère nativement le tactile

### Manette
- Non applicable — jeu de dessin créatif

Amuse-toi bien et laisse parler ta créativité !
